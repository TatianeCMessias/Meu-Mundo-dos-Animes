# Meu Mundo dos Animes

Uma aplicação web desenvolvida para apresentar e organizar informações sobre animes de forma simples, intuitiva e responsiva.

## Sobre o projeto
O Meu Mundo dos Animes é uma aplicação web criada como projeto de aprendizagem em desenvolvimento front-end.
A proposta é apresentar um pequeno catálogo de animes, permitindo visualizar informações de forma organizada por meio de cards, seções e uma galeria de imagens.
O projeto também teve como foco a utilização de HTML semântico, CSS responsivo e boas práticas de acessibilidade.

 ## Objetivos
- Praticar a utilização do HTML5;
- Aprender e aplicar HTML semântico;
- Desenvolver layouts utilizando CSS3;
- Trabalhar com design responsivo;
- Aplicar conceitos básicos de acessibilidade;
- Organizar e publicar um projeto no GitHub;
- Desenvolver um projeto para compor o portfólio.

## Animes apresentados
O catálogo apresenta os seguintes animes:
- O Diário da Apotecária
- Frieren
- O Sabor do Calabouço
- One Piece
- Meu Casamento Perfeito
- SPY x FAMILY
- Funcionalidades

## O projeto possui
- Cabeçalho com nome do projeto e menu de navegação;
- Seção Hero com título, descrição e botão de chamada para ação;
- Seção Sobre;
- Cards com informações sobre os animes;
- Galeria de imagens relacionadas ao tema;
- Seção de contato;
- Links para redes e informações de contato;
- Layout responsivo;
- Recursos básicos de acessibilidade;
- Estrutura utilizando HTML semântico.
  
## Tecnologias utilizadas
- HTML5 — estrutura e semântica da página;
- CSS3 — estilização e responsividade;
- Visual Studio Code — ambiente utilizado para desenvolvimento;
- GitHub Pages — publicação do projeto;
- Google Chrome — navegador utilizado para testes;
- ChatGPT — ferramenta utilizada como apoio durante o desenvolvimento.

## Responsividade

A aplicação foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência adequada em:

- Celulares;
- Tablets;
- Desktops.

Também foram utilizados recursos de CSS para evitar a rolagem horizontal em diferentes dispositivos.

## Acessibilidade

Durante o desenvolvimento, foram aplicadas algumas práticas de acessibilidade, como:

- Utilização do atributo alt nas imagens;
- Hierarquia correta dos títulos;
- Utilização de elementos HTML semânticos;
- Organização adequada do conteúdo;
- Estrutura pensada para facilitar a navegação e compreensão da página.
